# Epic

Modernize the Tax Calculator application with automated testing, containerization, and CI/CD deployment on IBM Cloud.

# User Stories

1. As a developer, I want a reusable tax calculation module so that I can test business logic independently from the UI.
2. As a developer, I want Jasmine unit tests in the project so that calculation logic is validated automatically.
3. As a developer, I want the app packaged in a Docker image so that it runs consistently across environments.
4. As a DevOps engineer, I want the image pushed to IBM Cloud Container Registry so that it can be deployed from a central registry.
5. As a DevOps engineer, I want a Tekton pipeline that runs tests before image build so that broken code is blocked from deployment.
6. As a user, I want the latest tested image deployed to IBM Cloud Code Engine so that I can access the calculator online.
